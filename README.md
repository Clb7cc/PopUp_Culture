# PopUp Culture 🏢✨

> **Toronto's Premier Short-Term Space & Pop-Up Marketplace**  
> Discover and book premier short-term storefronts, event lofts, galleries, rooftops, and creative studios across Downtown Toronto — solo or co-shared.

---

## 🌟 Overview

**PopUp Culture** connects independent creators, brands, artists, and event organizers with verified space hosts in Toronto. Whether you need a Queen West glasshouse storefront for a weekend fashion pop-up or want to **co-share** a Kensington Market loft with other artists to split costs, PopUp Culture makes short-term leasing frictionless, legally protected, and transparent.

---

## 🚀 Key Features

### 1. 🤝 Multi-Artist Co-Sharing (New!)
- **Split-Cost Zones:** Venues with co-sharing enabled allow multiple artists to lease dedicated zones (e.g., Front Retail Display, Central Studio Stage, Rear Gallery Wall) simultaneously.
- **Independent Protection:** Each co-tenant receives their own digital short-term space-use agreement and individual **$2M Commercial General Liability Insurance** coverage.
- **Interactive Application Workflow:** Browse existing co-tenants and apply directly for open zones with custom date ranges and art category tags.

### 2. 🗺️ Real-Time Interactive Leaflet Map
- **OpenStreetMap & CartoDB Tiles:** Dynamic interactive map of Downtown Toronto venues built on Leaflet.
- **Custom Price Badges:** Color-coded pins highlighting standard spaces vs. co-sharing spaces.
- **Preview Drawer:** Click any pin to inspect ratings, neighborhood tags, available slots, and pricing instantly.
- **Theme-Aware Tiles:** Automatically switches between CartoDB Light and Dark basemaps depending on the active color theme.

### 3. 🎨 Modern Design & Dark Mode
- **Curated Aesthetics:** Vibrant typography (`Archivo` & `DM Sans`), glassmorphism cards, subtle micro-animations, and responsive layouts.
- **System & Persistent Dark Mode:** Toggle seamlessly between Light and Dark mode with persistence in `localStorage`.
- **Robust Error Handling:** Integrated `SafeImg` fallback system ensuring visual consistency even if external image CDNs experience interruptions.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite 6
- **Routing:** TanStack Router (file-based routing)
- **Styling:** Vanilla CSS + Tailwind CSS v4 variables + custom animations
- **Mapping:** Leaflet & React-Leaflet (OpenStreetMap + CartoDB tiles)
- **Icons:** Lucide React

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation & Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Clb7cc/PopUp_Culture.git
   cd PopUp_Culture
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.
